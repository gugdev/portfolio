# Portfólio — Gustavo Alencar Matos

Portfólio profissional criado para apresentar minha formação, áreas de interesse e participação em projetos de software, IA aplicada e automação.

**Site publicado:** [gustavo-alencar.vercel.app](https://gustavo-alencar.vercel.app)

## Sobre o projeto

O site reúne cinco projetos desenvolvidos em equipe e descreve, de forma transparente, a minha atuação em cada um deles. A interface foi pensada para ser direta, responsiva e acessível, com identidade visual em tons de roxo e animações sutis.

Principais recursos:

- apresentação profissional e currículo para download;
- projetos com responsabilidades, tecnologias e links de referência;
- detalhes expansíveis com desafio, solução e situação atual de cada projeto;
- imagens reais de PraxUs AI, BinGo e ARAS;
- efeitos de cursor, progresso de leitura e revelação no scroll;
- layout responsivo para desktop e dispositivos móveis;
- respeito à preferência de redução de movimento do sistema.

## Tecnologias

- Next.js 16 e React
- TypeScript
- CSS responsivo
- `next/image` para otimização de imagens
- Vercel para hospedagem e entrega contínua

## Executar localmente

Requisitos: Node.js 20 ou superior e pnpm.

```bash
pnpm install
pnpm dev
```

Acesse `http://localhost:3000` no navegador.

Para validar a versão de produção:

```bash
pnpm build
pnpm start
```

## Estrutura principal

```text
app/
  components/       efeitos interativos do cliente
  globals.css       identidade visual e responsividade
  layout.tsx        metadados e estrutura global
  page.tsx          conteúdo da página principal
public/

```
